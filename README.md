# NEXORA HOME — Smart Living OS 🏠

NEXORA HOME is a modern smart home management dashboard built with **HTML, CSS, and Vanilla JavaScript**. It provides a centralized interface for monitoring and controlling smart-home devices, rooms, energy usage, security, automation, and system activity.

### ✨ Features

* 🏠 Smart home dashboard
* 💡 Smart device control
* 🌡️ Air conditioner and temperature controls
* 🛋️ Room-based device management
* ⚡ Energy monitoring and analytics
* 🔐 Home security monitoring
* 📹 Security camera status
* 🚪 Smart door lock controls
* 🤖 Home automation scenes
* 🔔 Real-time notifications and alerts
* 🌙 Dark and Light themes
* 🔎 Command/search interface
* 🕐 Live clock and dynamic greeting
* 💾 Local storage for application state
* 📱 Responsive interface for different screen sizes
* 🔊 Interactive sound/haptic feedback

### 🛠️ Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript
* Node.js
* LocalStorage
* SVG Icons
* Google Fonts

The JavaScript application follows a vanilla JavaScript architecture and maintains application state for devices, rooms, automations, notifications, security, and energy metrics.

### 🚀 Run Locally

```bash
git clone YOUR_REPOSITORY_URL
cd new-web
npm install
npm start
```

Then open:

```text
http://localhost:3000
```

The included Node.js server uses port `3000` by default and serves `index.html` as the main page.

NEXORA HOME demonstrates how a modern smart-home interface can bring **device management, security, energy monitoring, automation, and analytics** together in a single web-based control center.
